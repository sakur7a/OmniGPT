# OmniGPT 0.3.0：公式规则、导出与轻量 UI

## 公式复制

默认仍是纯文本 Markdown，不附带 KaTeX/MathML HTML。行内公式用 `$x_i$`，独立公式用单独成行的 `$$`；不是一律用双美元符号。保留原来的行内/独立语义，不用公式长度、宽度或居中样式猜测。优先使用明确的 TeX 定界符，其次是渲染器本身的显示标记。没有 TeX 源码时不把朗读标签冒充 LaTeX。

面板「更多选项 → 公式复制」可切换为 LaTeX 定界符：行内 `\(x_i\)`，独立 `\[ ... \]`。**Alt＋双击公式**只复制 TeX，不加任何定界符，便于粘进已有公式环境。正常双击和含公式的选区复制遵循所选格式。`G_k` 与 `G\_k` 保持原义，不互相改写。

复制设置只控制渲染公式的复制，不全局改写 API 导出的原始正文。页面 DOM 导出固定使用 Markdown 数学格式；API 导出保留原文已有定界符，以免正则转换误伤代码或普通文本。原生 ChatGPT 回复复制按钮可能绕过 copy 事件；本脚本仍不全局替换 Clipboard API。

参考：[Obsidian 数学语法](https://help.obsidian.md/advanced-syntax)、[KaTeX displayMode](https://katex.org/docs/options)、[Clipboard API](https://www.w3.org/TR/clipboard-apis/)。

## 面板

启动只创建入口，首次打开才构造面板。主面板只有范围、格式、导出文件、复制 Markdown；更多选项折叠。支持浅色/深色、窄屏、Escape 关闭、键盘焦点和可读进度。当前版本号显示在标题旁。

当前对话默认「完整对话优先」，可手动选择「仅已加载页面（离线）」。历史对话可以限制最近 50 或 200 条，默认只访问当前账号历史列表，不扫描其他工作区。复制 Markdown 只适用于当前对话，避免意外向剪贴板写入整个历史。

导出时显示已完成、成功、失败数量，并可取消。关闭面板会取消正在读取的任务。多分片改为逐个点击保存，不自动弹出一批下载请求，不引入 ZIP 库；关闭面板会释放尚未保存的分片。

## 导出修复

- DOM 回退按页面顺序收集，不再先导出所有用户消息再导出助手消息；复制和页面导出复用同一套公式/代码/基础表格序列化。
- API 只导出当前分支用户与助手正文，排除隐藏、控制和工具消息。不再在 current_node 缺失时把所有备选回答混合。只有唯一叶节点时才允许推断分支，并明确警告。
- 保留 API 正文缩进、空行和公式源码，不对整个文档做全局空白清洗。Markdown/TXT 元数据可以关闭；完整性警告始终保留。JSON 始终保留结构化来源与警告，**不是原始账号备份或原生聊天恢复文件**。
- 历史分页去重、识别 has_more/total、阻止重复分页循环，加入数量与分页安全上限。默认并发 2 个详情请求。
- 20 秒单次请求超时覆盖响应体；AbortController 可取消；401/403/404 至多一次刷新重试，短暂限流/服务错误最多两次退避重试。日志不输出 token 或私有响应正文。
- Markdown、TXT、JSON 和参考分片均保留失败明细；全部失败不生成看似成功的空归档。
- 分片按消息边界，约 90 万字符为软目标；超长单条消息保持完整，不切断公式/代码块，也不生成只有封面的空分片。

## 边界与性能

「页面导出」只能拿到已加载 DOM，文件与 UI 均标记可能缺失屏幕外消息。历史列表不保证包含归档、项目或其他工作区未列出的对话。图片和附件仅保留可用引用/占位，不下载二进制资源。

默认无持续观察器、无轮询、无 selectionchange 工作、无全页公式缓存；不劫持 fetch/XHR/Clipboard API，也不默认改写 Range/Selection。只有主动复制/双击或导出才处理相关内容。样式不使用毛玻璃、动画或外部字体；无第三方运行时依赖。大归档仍需要内存及格式化时间，并非零开销；较大历史建议先用 50/200 条范围验证。

保留旧 9 项 Node 和 20 项浏览器回归，新增 22 项导出与 20 项浏览器回归。CI 在发布前执行所有测试，包含真实系统剪贴板 MIME、键盘复制/粘贴和下载测试，其他路径使用代表性 DOM 和模拟 API。测试并不启动桌面微信/Obsidian或登录后的 ChatGPT，因此不宣称这些应用端到端全覆盖。

更新后刷新已经打开的 ChatGPT 标签页，再重新复制。Greasy Fork 同步取决于账号侧已配置的同步/Webhook，GitHub Release 成功不代表 Greasy Fork 已同步。

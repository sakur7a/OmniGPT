# OmniGPT 0.3.7 — Code blocks in copied replies

The v0.3.6 math-copy serializer treated editable CodeMirror content as an
ordinary editor to skip. In a reply containing math, the code card could be
reduced to its language label. A read-only CodeMirror card could also mix the
label into the code rather than use it as the Markdown fence language.

The serializer now recognizes ChatGPT-style CodeMirror cards, excludes their
controls, preserves code indentation and blank lines, and uses a safe Markdown
fence. Selections that begin or end inside a card retain only the selected part.
Copying only within an editor, code-copy buttons, and replies without supported
math continue to use their native behavior.

For a virtualized CodeMirror editor, the script reads its attached document when
available, including lines outside the rendered viewport. If a selected gap is
present but the document cannot be read, copy and quote compatibility fall back
to native behavior. Offline page export instead records a placeholder and warning.
CodeMirror's attached view is not a stable ChatGPT public API, so future site or
browser changes can still require compatibility updates.

## Verification

```sh
npm run check
python test/browser-regression.py
python test/browser-v030.py
python test/browser-current-dom.py
```

The browser fixtures cover mouse-drag selection and reply-copy actions, read-only
and editable code cards, partial selections, code fences, virtualization and
fallbacks. An additional local test used an actual CodeMirror 6 editor with a
1,000-line document whose viewport contained only 36 rendered lines. These are
browser tests on isolated pages, not verification of the user's signed-in ChatGPT
session or every userscript manager.
